# Python 私房课：从零基础、逆向思维到生产级 AI Agent 开发

这是一个面向中文读者的 Python 系统课程仓库。课程从基础运行模型、函数、数据与异常开始，逐步进入文件安全、工程化、HTTP/API、异步与可靠性，再以**模型输出不是授权**、**离线合同优先**和**副作用默认隔离**为原则，构建可审查的 LLM、RAG、Agent、评测与运行准备教学项目。

> 本仓库的目标不是堆叠某个框架或 API，而是让读者能从失败模式、输入输出合同、权限边界、测试和恢复要求倒推设计。

## 从这里开始

初学者应先阅读 `01_教材章节/chapters/` 中的模块 0–2，再按章节的“本章项目映射”进入可运行项目。每章都有 25 个编号教学部分、快测、代码阅读、Debug、编程、逆向设计和课后项目；外部资料均在章节末尾的 References 中标注。

| 学习阶段 | 模块 | 重点 |
|---|---|---|
| Python 基础与机制 | 0–4 | 运行模型、数据、函数、异常、文件、模块、类型、测试与受控插件。 |
| 工程与服务可靠性 | 5–8 | 项目结构、CLI、HTTP/API、数据库、异步、礼貌采集、状态机、取消与恢复。 |
| AI 与 Agent 合同 | 9–15 | 严格 Schema、来源约束、离线评测、有限状态、审批、委派、发布门禁与运行准备。 |

## 快速验证

各项目使用独立的 `pyproject.toml` 和测试。进入某个项目目录后，按照其 README 创建虚拟环境、安装开发依赖并运行质量门。例如：

```bash
cd "02_可运行项目/projects/02-text-analyzer"
python -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m pytest
.venv/bin/python -m mypy
.venv/bin/python -m ruff check src tests
```

课程发布记录保留了已完成的离线质量证据：教材层 32 项 `unittest` 与项目层 280 项 pytest，共 **312 项**官方全书回归；各项目的 mypy 与 Ruff 结果、局部读者路径审校和出版门禁均可在 `03_出版与审校记录/records/` 中追溯。

## 安全与能力边界

本课程把不可信文本视为数据，而非指令或权限。模型只能提出候选；应用代码必须验证、授权并记录结果。项目 9 的受控真实烟雾只验证最小接线，项目 10 的哈希嵌入是教学替身；项目 11–15 均为纯数据、离线合同与静态夹具，不连接真实模型、工具、数据库、文件副作用、秘密、部署或生产服务。

因此，测试通过不等于真实模型质量、生产安全、访问授权、部署成功、成本可控、容量充足或恢复完成。任何真实能力采用都应单独完成架构设计、威胁建模、最小权限、审批、测试、评测与运行审查。
