# 最小运维 Runbook 模板

> **数据最小化规则：** 不记录秘密值、用户正文、提示词、完整配置、生产端点、完整 trace、工具原始结果或个人数据。只记录受控 ID、版本、状态、时间、决定与理由类别。

| 字段 | 必填 | 说明 |
|---|---:|---|
| Runbook ID / 版本 / 复审日期 | 是 | 受控标识、适用版本和下次复审。 |
| 触发条件与影响级别 | 是 | 什么信号触发，用户/系统影响如何分级。 |
| 立即暂停步骤 | 是 | 如何停止新工作；禁止自动批准、自动重放未知外部动作。 |
| 最小证据 | 是 | 版本、阶段、门禁状态、受控事件 ID 与时间。 |
| 禁止动作 | 是 | 不打印秘密、不绕过审批、不下载生产备份、不扩大权限。 |
| 结果未知处置 | 是 | 对账、幂等查询、人工复核和升级路径。 |
| 恢复与回滚 | 是 | 版本兼容、恢复演练前提、验证和停止条件。 |
| 升级与沟通 | 是 | 责任角色、响应窗口、联系失败时的替代路径。 |
| 复盘入口 | 是 | 事实、改进项、回归案例和复审责任。 |
