# 文本分析工具

该项目演示如何将文本规范化、统计与报告格式化拆分为可测试函数，并通过标准输入提供最小命令行交互。

| 项目内容 | 当前实现 | 验证方式 |
|---|---|---|
| 文本规范化 | 合并多余空白。 | `normalize_text` 单元测试。 |
| 文本统计 | 返回字符数、词数和行数。 | `analyze_text` 单元测试。 |
| 报告输出 | 将统计字典格式化为可读中文报告。 | `format_report` 单元测试。 |
| 输入边界 | 非字符串输入抛出明确 `TypeError`。 | 异常断言。 |

在教材根目录运行：

```bash
printf 'a b\n' | python3 projects/02-text-analyzer.py
python3 -m unittest tests/module_02/test_text_analyzer.py -v
```

当前版本只处理标准输入中的文本，不会读取用户文件、访问网络或保存数据。后续将加入文件输入、配置、日志和更完整的错误恢复策略；所有外部路径和内容必须在读取前验证。
