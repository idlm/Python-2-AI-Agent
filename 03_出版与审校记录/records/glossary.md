# 全书术语表

**维护规则：** 每一个术语第一次在正文出现时均以“中文主名（英文名，缩写）”呈现；本表记录标准定义、首现章节和禁止混用的表达。

| 中文主名 | 英文 / 缩写 | 标准定义 | 首现章节 | 避免混用 |
|---|---|---|---|---|
| 毕业作品 | Capstone Project | 用来验证读者能整合课程核心能力的最终可运行系统。 | 0.1 | 不称为“最后的大作业”，以免忽略系统验收。 |
| 程序 | Program | 为完成特定任务而按顺序描述操作的一组指令及其相关数据。 | 0.2 | 不把任何文本文件都称为程序。 |
| 源代码 | Source Code | 人编写、供解释器或编译器读取的程序文本。 | 0.2 | 不与运行中的进程混用。 |
| 解释器 | Interpreter | 读取并执行 Python 源代码的程序。 | 0.2 | 不称为“Python 代码本身”。 |
| 终端 | Terminal | 以文本命令与操作系统或程序交互的界面。 | 0.2 | 不与操作系统、命令行解释器混为同义词。 |
| 命令行解释器 | Shell | 在终端中读取并执行操作系统命令的程序。 | 0.2 | 不与 Python 解释器混用。 |
| 当前工作目录 | Current Working Directory，CWD | 命令执行时默认查找和创建相对路径文件的位置。 | 0.2 | 不简称为“项目名”。 |
| 路径 | Path | 用于定位文件或目录的一串层级名称。 | 0.2 | 不将路径等同于文件内容。 |
| 输入 | Input | 程序执行时接收的数据、事件、文件或参数。 | 0.2 | 不只限于键盘输入。 |
| 输出 | Output | 程序执行后产生的可观察结果，如文本、文件、网络响应或状态变化。 | 0.2 | 不把 `print()` 限定为唯一输出。 |
| Traceback | Traceback | Python 在未处理异常发生时给出的调用路径和错误定位信息。 | 0.2 | 不将其误称为“错误原因本身”。 |
| 变量名 | Variable Name | 指向对象的标识符；赋值会建立或更新名称绑定。 | 1.2 | 不把变量名本身当作对象内容。 |
| 对象 | Object | Python 运行时可被名称引用、具有类型与值的实体。 | 1.2 | 不与变量名混用。 |
| 可变对象 | Mutable Object | 内容可在原对象上改变的对象，如列表和字典。 | 1.2 | 不等同于“变量能重新赋值”。 |
| 不可变对象 | Immutable Object | 内容不能原地改变的对象，如字符串、整数和元组。 | 1.2 | 不表示名称不可重新绑定。 |
| 条件分支 | Conditional Branch | 按布尔条件选择不同执行路径的控制流结构。 | 1.5 | 不与循环混为同一机制。 |
| 迭代 | Iteration | 按顺序逐项访问集合或数据流中元素的过程。 | 1.6 | 不只指 `for` 语句。 |
| 函数 | Function | 可被调用、接收输入并可能返回结果的命名代码单元。 | 2.1 | 不把所有代码块都称作函数。 |
| 副作用 | Side Effect | 函数除返回值外造成的可观察状态变化，如写文件或修改全局状态。 | 2.2 | 不与错误混为同义词。 |
| 作用域 | Scope | 名称在程序中可见和可解析的范围。 | 2.3 | 不等同于对象生命周期。 |
| 闭包 | Closure | 能在函数返回后仍引用其外层局部名称的函数。 | 2.3 | 不把所有嵌套函数都称为闭包。 |
| 类型注解 | Type Annotation | 为参数、返回值或变量说明预期类型的信息，供人和工具检查。 | 2.4 | 不表示 Python 自动强制运行时类型检查。 |
| 路径遍历 | Path Traversal | 通过 `..` 等路径成分越过预期目录边界的安全风险。 | 3.1 | 不与普通相对路径混为同义词。 |
| Dry Run | Dry Run | 只规划和报告将执行的操作，而不造成真实外部状态变化的运行方式。 | 3.2 | 不称为“已执行的归档”。 |
| 操作清单 | Operation Manifest | 记录预期或已发生操作的结构化文件，用于审计、诊断或回滚。 | 3.4 | 不与日志文件等同。 |
| 数据类 | Data Class，`dataclass` | 由 Python 标准库帮助生成初始化、表示等方法的类定义工具。 | 4.1 | 不表示所有类都应使用数据类。 |
| 协议 | Protocol | 描述对象应具备哪些方法或属性的结构化接口约定。 | 4.1 | 不强制要求继承共同父类。 |
| 组合优先 | Composition over Inheritance | 优先通过持有和协作对象扩展行为，而非为复用而形成深继承链的设计原则。 | 4.2 | 不表示完全禁止继承。 |
| 装饰器 | Decorator | 包装函数或对象以增加横切行为的机制。 | 4.3 | 不与被装饰函数本身混用。 |
| 生成器 | Generator | 通过 `yield` 惰性、逐项产生值的迭代器。 | 4.3 | 不等同于一次性创建的列表。 |
| 上下文管理器 | Context Manager | 控制资源进入、退出与异常清理的对象或结构，通常与 `with` 一起使用。 | 4.3 | 不与任意代码块混用。 |
| 插件注册表 | Plugin Registry | 保存被明确允许的插件名称及其实例或工厂的受控映射。 | 4.4 | 不等同于任意模块发现机制。 |
| 允许列表 | Allowlist | 明确允许、默认拒绝的规则集合。 | 4.4 | 避免使用带有肤色隐喻的替代术语。 |
| 动态导入 | Dynamic Import | 在运行时按模块或对象名称装载代码的机制。 | 4.4 | 不应直接对不可信配置启用。 |
| 虚拟环境 | Virtual Environment，venv | 为单个项目隔离 Python 解释器和已安装包的运行环境。 | 5.1 | 不等同于容器或完整操作系统隔离。 |
| 项目元数据 | Project Metadata | 描述项目名称、版本、兼容 Python 版本、依赖和入口等信息的声明。 | 5.1 | 不等同于运行时业务配置。 |
| 依赖 | Dependency | 项目运行、构建、测试或开发所需要的外部软件包。 | 5.1 | 不把 Python 标准库误记为第三方依赖。 |
| 可复现运行 | Reproducible Execution | 在明确环境、版本、输入和命令下，可由他人重新验证的运行过程。 | 5.1 | 不等于作者本机曾运行成功。 |
| 持续集成 | Continuous Integration，CI | 自动执行构建、测试、静态检查等质量门禁的集成实践。 | 5.1 | 不等同于自动部署或自动发布。 |
| `src` 布局 | `src` Layout | 将可安装包放在项目根目录下 `src/` 中的目录组织方式，以减少测试偶然从项目根目录导入源码的风险。 | 5.1 | 不等同于“任何名为 src 的文件夹都自动安全”。 |
| 可编辑安装 | Editable Install | 安装工具将项目以开发方式安装，使导入和命令入口指向当前工作树的安装模式。 | 5.2 | 不等同于跳过测试或省略项目元数据。 |
| 薄兼容层 | Thin Compatibility Layer | 为旧导入路径或旧命令提供的最小委托或重导出适配器，不应复制业务实现。 | 5.5 | 不等同于永久保留两套核心代码。 |
| 回归测试 | Regression Test | 用于确认改动没有破坏已建立外部行为契约的测试。 | 5.5 | 不等同于只测试新功能。 |
| 质量门禁 | Quality Gate | 合并、发布或继续交付前必须通过的自动化验证集合，例如测试、类型检查和静态检查。 | 5.5 | 不等同于“测试通过就自动发布”。 |
| 原子替换 | Atomic Replacement | 先完成临时文件写入，再用单次替换操作更新目标文件，以降低半写入文件风险的持久化策略。 | 5.5 | 不保证跨机器并发事务或远程备份。 |
| 备份文件 | Backup File | 在高风险写入前保留的旧内容副本，用于人工核对和恢复。 | 5.5 | 不等同于完整灾难恢复或版本控制。 |
| 故障复盘 | Incident Postmortem | 基于事实记录影响、检测、根因、处置与防复发措施的改进文档。 | 5.5 | 不以归责个人为目的。 |
| HTTP 合同 | HTTP Contract | 对 API 的方法、路径、输入 Schema、输出 Schema、状态码、错误格式与可观察行为的明确约定。 | 6.1 | 不等同于某个框架的路由装饰器。 |
| 资源 | Resource | API 中可被标识、创建、读取、更新或删除的领域对象或集合。 | 6.1 | 不将任意动作名称都称作资源。 |
| 请求模式 | Request Schema | API 明确接受的请求字段、类型、范围和额外字段规则。 | 6.1 | 不等同于任意 JSON 字典。 |
| 响应模式 | Response Schema | API 承诺返回给调用方的字段、类型与结构。 | 6.1 | 不自动包含领域对象或数据库对象的全部属性。 |
| 状态码 | HTTP Status Code | HTTP 响应中表明请求结果类别的数值代码。 | 6.1 | 不将所有失败统一返回 `200`。 |
| 请求 ID | Request ID | 标识单次请求、用于关联响应与脱敏运行日志的非秘密相关标识。 | 6.2 | 不等同于用户身份、认证令牌或追踪用户行为的永久 ID。 |
| 依赖注入 | Dependency Injection，DI | 由框架或组合根向函数明确提供其所需资源或服务的方式。 | 6.2 | 不等同于隐藏全局变量或万能服务定位器。 |
| 仓储 | Repository | 封装领域对象持久化和读取操作、隔离数据库细节的组件。 | 6.3 | 不等同于代码版本仓库。 |
| 数据库事务 | Database Transaction | 一组数据库操作的提交或回滚边界，使成功和失败状态有明确语义。 | 6.3 | 不等同于单次 SQL 调用必然自动安全。 |
| 参数化查询 | Parameterized Query | 将固定 SQL 结构与数据参数分离、由驱动绑定数据值的查询方式。 | 6.3 | 不表示可把表名、列名或 SQL 关键字作为任意参数传入。 |
| 协程 | Coroutine | 由 `async def` 定义、可在 `await` 处暂停并恢复的可等待执行单元。 | 6.4 | 不等同于已经运行的 Task。 |
| 结构化并发 | Structured Concurrency | 将相关并发任务纳入共同作用域，使等待、失败、取消和收尾具有可推理边界的方式。 | 6.4 | 不等同于无引用的后台任务。 |
| 任务组 | Task Group，`TaskGroup` | Python 3.11 中管理一组相关异步任务、等待收尾并传播失败的异步上下文管理器。 | 6.4 | 不等同于任意 Task 列表。 |
| 超时 | Timeout | 为操作的等待时间设置上限，并在超过预算后触发预定失败处理的机制。 | 6.4 | 不保证远端副作用已经撤销。 |
| 取消 | Cancellation | 向运行中任务请求停止、通常以 `CancelledError` 传播并要求清理后继续传递的控制流机制。 | 6.4 | 不等同于忽略任务或宣称远端操作未发生。 |
| HTTP 客户端 | HTTP Client | 代表程序向 HTTP 服务构造、发送、接收和关闭请求资源的组件。 | 7.1 | 不等同于单次 `get()` 函数调用或 API 服务端。 |
| 连接池 | Connection Pool | 客户端维护和复用网络连接、并可限制其数量的资源管理机制。 | 7.1 | 不等同于业务任务并发上限或远端访问许可。 |
| 连接超时 | Connect Timeout | 等待与目标主机建立网络连接的最长时间。 | 7.1 | 不等同于读取完整响应的时间上限。 |
| 读取超时 | Read Timeout | 等待收到响应下一数据块的最长时间。 | 7.1 | 不等同于整个业务流程的总时间预算。 |
| 连接池超时 | Pool Timeout | 等待从客户端连接池取得可用连接的最长时间。 | 7.1 | 不表示 DNS、网络或上游服务器必然故障。 |
| 重试策略 | Retry Policy | 对明确可重试失败设定最大次数、间隔和终止条件的合同。 | 7.1 | 不等同于对所有错误无限再发请求。 |
| 幂等 | Idempotence | 同一操作重复执行在目标状态上具有与执行一次相同效果的性质。 | 7.1 | 不由 HTTP 方法名自动保证，尤其不应假设写操作可安全重试。 |
| robots 规则 | robots.txt Rules | 站点发布的、面向特定 User-Agent 的技术访问规则，例如允许路径、Crawl-delay 与请求速率。 | 7.2 | 不等同于法律授权、条款同意、版权许可或隐私同意。 |
| 信号量 | Semaphore | 以可用计数限制同时进入某一异步临界资源区的同步原语。 | 7.2 | 不等同于连接池、全局速率限制或线程同步工具。 |
| 请求节奏器 | Request Pacer | 为同一来源安排相邻请求开始时间最小间隔的组件。 | 7.2 | 不等同于响应处理时间、网络超时或跨站点全局配额。 |
| JSON Lines | JSONL | 每一行均为一个完整 JSON 值、通常为对象的文本记录格式约定。 | 7.3 | 不等同于向单个 `.json` 文件连续追加多个对象。 |
| 内容去重 | Content Deduplication | 基于受控的规范输入生成标识并跳过等价记录的存储策略。 | 7.3 | 不等同于完整增量同步、来源认证或版本控制。 |
| 清单 | Manifest | 记录数据集版本、计数、标识和更新时间等派生摘要的结构化文件。 | 7.3 | 不等同于完整正文、日志或灾难恢复备份。 |
| 显式恢复 | Explicit Recovery | 由调用方明确触发、从已验证权威记录重建派生状态的恢复动作。 | 7.3 | 不等同于程序静默忽略损坏或猜测正常状态。 |
| 服务工作流 | Service Workflow | 将请求接受、状态、执行、失败、取消、恢复和对外可观察行为组织为明确合同的服务级过程。 | 8.1 | 不等同于单个 HTTP 路径、后台函数或框架名称。 |
| 有限状态机 | Finite-State Machine，FSM | 用有限状态集合及其允许转换描述对象生命周期的模型。 | 8.1 | 不等同于可任意修改字符串状态的字段。 |
| 幂等键 | Idempotency Key | 调用方提供、用于关联同一业务接受操作重试的受控标识。 | 8.1 | 不等同于用户身份、请求 ID、全局内容去重或外部副作用保证。 |
| 公开视图 | Public View | 对内部领域记录经过有意字段筛选后向 API 或 CLI 返回的稳定数据模型。 | 8.1 | 不等同于自动序列化整个内部对象。 |
| 恢复候选 | Recovery Candidate | 因中断而无法确定外部进度、需由明确策略判断是否恢复或重放的工作项。 | 8.1 | 不等同于可以安全自动重跑的任务。 |
| 反压 | Backpressure | 当消费者处理能力不足时，通过有界容量、等待或拒绝把压力传回生产者的机制。 | 8.2 | 不等同于把队列设为无界后延迟报错。 |
| 进程内队列 | In-Process Queue | 仅在一个运行中进程及其事件循环内保存工作项的内存队列。 | 8.2 | 不等同于持久化、跨进程或跨重启消息队列。 |
| Worker | Worker | 从队列领取受控工作并执行固定处理器、更新任务状态的执行单元。 | 8.2 | 不等同于任意由用户请求指定的 callable。 |
| Drain | Drain | 在不再接受或新增当前批次工作后，等待已入队项目完成并让 worker 有序退出的过程。 | 8.2 | 不保证崩溃、超时或强杀时任务不会丢失。 |
| 应用生命周期 | Application Lifespan | 服务开始接收请求前的初始化与停止时清理所覆盖的应用运行边界。 | 8.3 | 不等同于某个单独请求、模块导入或永久后台服务。 |
| `202 Accepted` | HTTP 202 Accepted | 表明服务已接受请求以供处理，但尚未表示处理已完成的 HTTP 响应状态。 | 8.3 | 不等同于任务成功、投递持久或外部副作用完成。 |

| 系统提示 | System Prompt | 应用预先审查并作为高层行为引导发送给模型的固定消息内容。 | 9.1 | 不等同于用户输入、访问控制或安全边界。 |
| 结构化输出 | Structured Output | 按预定义数据形状返回模型候选数据的方式，例如严格 JSON Schema。 | 9.2 | 不等同于只返回可解析 JSON、事实核验或工具调用。 |
