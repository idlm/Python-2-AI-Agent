# 《Python私房课：从零基础、逆向思维到生产级 AI Agent 开发》课程目录

**当前范围：** 模块 0–15 已完成当前教学与项目收束；全书已进入出版质量阶段。  
**当前官方回归：** 32 项教材 `unittest` + 280 项项目 pytest = **312 项**；项目 1–15 均通过 mypy 与 Ruff。  
**重要边界：** “当前收束完成”表示课程当前范围、离线合同和回归已完成，不表示真实生产部署、模型安全、事实正确性、容量、成本、秘密、备份恢复或副作用已经验收。

## 学习路线

| 模块 | 主题 | 章节数 | 主要项目/产物 | 完成后的能力边界 |
|---:|---|---:|---|---|
| 0 | 学习路线、环境、Traceback 与可复现练习 | 4 | 环境与 Traceback 示例 | 能复现、阅读和记录错误；不等于工程发布。 |
| 1 | Python 基础、控制流、数据结构与 I/O | 8 | 命令行任务管理器 | 能写受控 CLI 与基础数据操作。 |
| 2 | 函数、作用域、类型注解与文本分析 | 5 | 文本分析工具 | 能把输入、处理、输出写成函数合同。 |
| 3 | 文件、路径、JSON、日志与异常 | 4 | 自动归档系统 | 能采用 Dry Run、清单和显式回滚处理文件。 |
| 4 | 类、组合、Python 机制与安全插件 | 4 | 安全插件系统 | 能用 Protocol、允许列表和字段闭集限制扩展。 |
| 5 | 工程化、测试、类型、静态检查、CI | 5 | CLI 工具平台 | 能建立 `src`、虚拟环境、质量门与可复现项目。 |
| 6 | HTTP、API、SQLite、asyncio | 4 | 知识笔记 API | 能理解 API 合同、事务、超时与取消。 |
| 7 | 受控 HTTP 客户端、礼貌并发与 JSONL | 3 | API 采集器 | 能实现 HTTPS/robots/重试/恢复边界。 |
| 8 | 服务工作流、队列、生命周期与恢复 | 3 | 受控工作流服务 | 能建模状态、幂等、反压、取消和恢复候选。 |
| 9 | LLM 合同、严格 JSON、本地验证与评测 | 3 | LLM 合同客户端 | 模型只产生受控候选；真实烟雾只验证接线。 |
| 10 | RAG 语料、检索、来源约束与评测 | 4 | RAG 合同工作台 | 使用教学嵌入替身；不假定真实 embedding 能力。 |
| 11 | 无框架受限 Agent 核心 | 4 | 受限 Agent 核心 | 先状态、纯工具、预算、审批、事件和离线评测。 |
| 12 | 框架对照与采用前合同 | 4 | 框架采用合同工具包 | 框架仅编排；不接入真实框架、持久化或工具。 |
| 13 | 多 Agent 委派与权限不扩散 | 4 | 委派合同工具包 | 纯数据委派；不创建真实 worker、并发或工具执行。 |
| 14 | 评测、追踪、发布与回滚门禁 | 4 | 评测基线与发布门禁工具包 | 离线基线不等于真实生产评测或发布。 |
| 15 | 配置、秘密、健康、恢复与 Runbook | 4 | 运行准备与恢复合同工具包 | 运行准备合同不等于部署、秘密接线或恢复证明。 |

## 推荐阅读方式

初学者应按 0 → 5 完成语言和工程基线，再学习 6 → 8 的服务与可靠性，再学习 9 → 15 的 LLM、RAG、Agent、评测和运行准备。若以 Agent 设计为目标，应至少先掌握模块 5、8、9、10 的输入/输出合同、状态、恢复和评测理念，避免从框架或自由工具调用开始。
