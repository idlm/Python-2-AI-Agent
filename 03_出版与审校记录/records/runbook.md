# 全书运行手册（Runbook）

**适用范围：** 《Python私房课》教材、项目 1–15、离线静态评测与出版质量材料。  
**不适用范围：** 真实生产服务、云、Kubernetes、Docker、数据库、模型、秘密平台、MCP、支付、账户或高风险工具操作。

> **安全前提：** 本手册中的命令用于课程仓库的本地无网络验证。不要把教学夹具、默认无执行 CLI 或离线合同误当作真实生产部署方案。禁止将秘密、用户正文、提示词、完整供应商响应、生产端点或真实备份写入问题报告、测试夹具、日志、截图或出版材料。

## 1. 运行前检查

| 检查项 | 操作 | 通过条件 | 失败时处理 |
|---|---|---|---|
| 工作目录 | 仓库根目录（含 `01_教材章节/chapters/`、`02_可运行项目/projects/`、`03_出版与审校记录/records/`） | 上述三个目录都存在。 | 不在错误目录执行批量命令。 |
| 解释器 | `python3 --version` | Python 3.11+。 | 使用项目 README 所示虚拟环境。 |
| 项目环境 | `02_可运行项目/projects/<项目>/.venv/bin/python -m pytest` | 可执行且不依赖真实网络。 | 按 README 重新创建 `.venv` 并可编辑安装。 |
| 敏感数据 | 检查新增夹具、报告、日志、示例 | 不含秘密、真实正文、prompt、端点或原始响应。 | 立即停止提交/发布，删除泄露物并轮换真实凭据（若适用）。 |

## 2. 标准质量命令

| 范围 | 命令 | 预期 |
|---|---|---|
| 单个项目测试 | `cd 02_可运行项目/projects/<项目> && .venv/bin/python -m pytest` | 所有测试通过。 |
| 单个项目类型检查 | `cd 02_可运行项目/projects/<项目> && .venv/bin/python -m mypy` | 无严格类型错误。 |
| 单个项目静态检查 | `cd 02_可运行项目/projects/<项目> && .venv/bin/python -m ruff check src tests` | 无 Ruff 错误。 |
| 模块 0–15 全量回归 | 阅读 `03_出版与审校记录/records/module_15_full_regression.log` 或重跑同等范围命令 | 当前基线为 312 项测试、项目 1–15 的 mypy/Ruff 均通过。 |
| 章节结构审查 | `grep -Ec '^## [0-9]+\. ' 01_教材章节/chapters/<章节>.md` | 需要严格 25；练习配额见第 21–25 节。 |

项目 1、6、7 的既有 Ruff 基线不含 `examples/`；全量回归沿用每个项目既有的 `src tests` 范围。项目 6、8 的 Starlette/httpx 弃用 warning 为记录中的第三方依赖 warning，不是测试失败。

## 4. 常见失败处置

| 症状 | 首先检查 | 处置 | 禁止动作 |
|---|---|---|---|
| pytest 失败 | 失败测试的最小夹具和最近修改 | 复现、定位合同、写/更新回归测试，再修复实现。 | 不删除测试或放宽断言以“恢复绿色”。 |
| mypy 失败 | 实际类型、可选值和容器不变性 | 显式建模类型；不要用无约束 `Any` 掩盖边界。 | 不用全局忽略或关闭 strict。 |
| Ruff 失败 | 导入、行长、简化与现代语法 | 按规则最小修复，复跑全套门禁。 | 不为了格式禁用整个规则集。 |
| 静态夹具错误 | 字段闭集、重复 ID、JSON、路径 | 保持错误为稳定夹具错误，修正公开夹具。 | 不静默忽略未知字段或读取任意路径。 |
| 报告出现正文/敏感字段 | 报告序列化清单和测试 | 停止发布、删除产物、收紧字段清单、添加泄露回归测试。 | 不用正则“脱敏”代替数据最小化设计。 |
| 结果未知 | 幂等键、外部状态、审批和对账流程 | 标记为未知，走受控查询/对账/人工复核。 | 不自动重试、自动标为成功或假设已回滚。 |
| 真实凭据疑似泄露 | 记录、日志、夹具、CI、截图 | 停止暴露、撤销/轮换、审计访问、修复来源和发布材料。 | 不在公开 issue 或聊天中粘贴密钥。 |

## 5. 停止条件与升级

应当停止自动化推进并升级给相应负责人（安全、隐私、业务、平台或人工审批者）的条件包括：秘密或个人数据暴露；未知外部副作用；权限/审批不一致；真实备份/恢复失败；评测硬阻断；关键案例未运行；Runbook 缺失；无法停止新工作；无法确认版本/配置/身份；或需要真实部署、支付、账户、传输、文件写入、数据库变更等操作。

## 6. 真实部署前的独立检查

真实部署不是本课程当前自动执行范围。若未来需要部署，必须独立完成威胁建模、数据分类、平台选择、身份与最小权限、秘密管理、网络暴露、资源/成本、备份恢复演练、遥测保留、告警/值班、Runbook、发布/回滚、法律/合规适用性和人工批准。仅当这些条件在目标环境中被审查和验证后，才可考虑小范围、可停止、可回滚的受控采用。
