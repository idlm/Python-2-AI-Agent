# 模块 0·第 0.3–0.4 章研究核对记录

**核对日期：** 2026-08-25（GMT+8）

| 官方资料 | 适用于教材的可核对结论 | 教材处理方式 |
|---|---|---|
| [Python 教程：Errors and Exceptions](https://docs.python.org/3/tutorial/errors.html) | 语法正确的语句仍可能在执行期触发异常；未被处理的异常通常会产生错误信息。错误输出末行给出异常类型和详情，前面部分为包含源代码位置的堆栈追踪。 | 第 0.3 章先区分语法错误与运行期异常，再采用“读最后一行、回到文件与行号、最小复现、修复后验证”的安全诊断顺序。避免教导初学者笼统捕获所有异常。 |
| [Python 教程：Virtual Environments and Packages](https://docs.python.org/3/tutorial/venv.html) | `venv` 创建包含特定 Python 安装与支持文件的虚拟环境；由哪个 Python 命令创建，就使用该版本作为环境基础。激活会调整 Shell 环境，使 `python` 指向该环境的解释器。官方将 `.venv` 列为常见目录名。 | 第 0.4 章把环境记录、解释器检查、`.venv`、依赖清单和最小复现流程作为学习可复现性的起点；强调激活不是魔法，且不把 `.env` 中的密钥写进版本库。 |

## 写作限制

1. 第 0.3 章只教初学者可安全执行的诊断操作；`try/except` 的完整工程策略留待后续异常处理章节。
2. 第 0.4 章先建立目录、版本和记录的稳定性，再逐步引入 `venv`；不以工具命令替代对解释器和依赖来源的理解。
3. 外部命令、环境变量和文件操作均标明副作用、适用系统与撤销或检查方式。
