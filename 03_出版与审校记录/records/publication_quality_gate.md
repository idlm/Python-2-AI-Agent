# 全书出版质量门禁

**适用对象：** 《Python私房课》每一次发布候选版本。  
**当前结论：** 本文件定义出版检查，不把当前通过状态表述为 PDF、纸质排版、真实生产系统或真实安全认证。

## 1. 发布判定规则

| 判定 | 条件 |
|---|---|
| 可进入下一出版审校 | P0 项全部通过；P1 项无未说明阻断；所有回归记录与正文相符。 |
| 条件通过 | 不影响学习安全或事实准确性的 P2 缺口有明确责任人、期限和记录。 |
| 阻断发布 | 任何秘密/个人数据泄露、代码/测试不通过、章节结构缺失、引用不可追溯、错误生产声明、失效链接未标注、项目路径错误、索引/Runbook 与正文矛盾。 |

## 2. P0：教材结构与练习

| 检查 | 通过标准 | 证据 |
|---|---|---|
| 章节编号 | 已纳入严格规范的章节均有 25 个固定编号部分。 | `grep -Ec '^## [0-9]+\. ' chapters/<章节>.md`。 |
| 练习配额 | 每章有至少 5 快测、2 代码阅读、2 Debug、3 编程、1 逆向设计和 1 课后项目。 | 第 21–25 节标题与正文。 |
| 零基础可读性 | 首现术语解释原理、为什么和边界；示例可从当前章节前置知识理解，并按角色完成可追溯试读。 | 正文审校、`records/bilingual_index.md`、`records/language_navigation_release_check.md` 与 `records/reader_review_protocol.md`。 |
| 项目映射 | 章节中提到的代码路径、命令、输入输出和失败案例都与项目实际一致。 | `records/repository-map.md`、README、测试。 |

## 3. P0：工程与可复现性

| 检查 | 通过标准 | 证据 |
|---|---|---|
| 项目基线 | 每个标准项目有 `src`、`pyproject.toml`、README、`.gitignore`、pytest、mypy、Ruff 和 Python 3.11/3.12 CI。 | 项目目录与 CI 文件。 |
| 全量回归 | 教材单元测试、项目 pytest、mypy 和 Ruff 在记录范围内全部通过。 | `records/module_15_full_regression.log`；当前 312 项测试。 |
| 受控失败 | 已知错误被建模、测试并映射到公开边界；不静默吞错。 | `records/traceback_index.md`、项目测试。 |
| 静态评测 | 夹具字段闭集、重复 ID、损坏 JSON/缺失文件、隐私报告与 CLI 模式均有测试。 | 项目 9–15 的测试与 README。 |

## 4. P0：事实、引用、链接与隐私

| 检查 | 通过标准 | 阻断示例 |
|---|---|---|
| 外部事实引用 | 每章外部事实使用数字引用且在文末 References 提供可访问来源。 | “官方要求/供应商支持”没有来源。 |
| 一手资料优先 | 运行、框架、模型、部署、安全类事实优先使用官方文档、标准或原始机构资料。 | 用搜索摘要、二手博客或模型记忆代替依据。 |
| 链接 | Markdown URL 格式正确；失效链接复核、替换或标注。 | 关键参考链接无效且未说明。 |
| 数据最小化 | 夹具、报告、日志、图例和正文不含秘密、真实用户正文、prompt、原始响应、完整 trace、生产端点。 | 真实 API key、完整生产请求或数据库 URL。 |
| 真实能力措辞 | 真实烟雾仅称为接线验证；替身只称教学替身；离线通过不称生产验收。 | 将 312 项测试宣传为模型/系统安全或真实部署证明。 |

## 5. P1：索引、决策与运行材料

| 检查 | 通过标准 | 位置 |
|---|---|---|
| 中英索引 | 可从中文或英文定位核心概念和首现章节；术语表中文主名无未解释的索引缺口。 | `records/bilingual_index.md`、`records/language_navigation_reaudit.log`。 |
| 读者试读 | 零基础、工程与 Agent 读者均有任务、问题等级与不含敏感内容的反馈路径；首轮试读有章节、项目命令、已知基线和去标识化登记/处置入口。 | `records/reader_review_protocol.md`、`records/reader_review_pilot_packet.md`、`records/reader_feedback_ledger.md` 与相关复核日志。 |
| Traceback 索引 | 区分教学异常、受控失败、退出码和公开错误。 | `records/traceback_index.md` |
| ADR | 跨模块决定说明背景、决定、后果、替代方案和证据。 | `records/adr/` |
| Runbook | 包含验证、评测、失败处置、停止条件和真实部署前检查。 | `records/runbook.md` |
| 状态记录 | `progress.md`、`project-status.md`、`test-status.md`、`repository-map.md` 与 manifest 一致。 | `records/` |

## 6. P1：可读性与一致性

出版审校应检查标题层级、模块命名、命令格式、代码围栏、术语一致性、表格可读性、中文标点、英文名称首现、链接文本、引用编号和重复段落。必要时对复杂代码增加“输入—处理—输出—失败边界”说明，而不是只展示 API 调用。

## 7. 最终签核记录模板

| 字段 | 必填 | 说明 |
|---|---:|---|
| 发布候选版本 | 是 | 教材/仓库的受控版本或提交标识。 |
| 结构、练习、代码、引用、链接、隐私、索引、ADR、Runbook | 是 | 每项记录通过、阻断或带期限的条件通过。 |
| 回归证据 | 是 | 记录日志路径、测试计数、解释器和已知 warning。 |
| 例外 | 是 | 例外范围、风险、责任人、截止日期和复审条件。 |
| 签核决定 | 是 | 发布、条件发布或拒绝；不记录秘密或用户正文。 |
