# Traceback 与受控失败索引

**目的：** 帮助初学者在“需要阅读 Python 异常”与“需要设计产品级公开错误”之间建立边界。Traceback 是调试证据；公开错误是对调用者的稳定合同。两者都不应包含秘密、用户正文、原始供应商响应或内部路径。

> **核心规则：** 教学脚本可故意抛出异常以练习阅读 Traceback；产品路径应在边界处捕获已知失败，输出受控错误类型、受控 JSON 或受控 HTTP 状态。不要用 `except Exception: pass` 隐藏错误。

## 1. 教学 Traceback 入口

| 场景 | 文件 / 章节 | 预期观察 | 学习目标 | 不应得出的结论 |
|---|---|---|---|---|
| 非数字转换 | `examples/module_00/traceback_lab.py`；0.2 | `ValueError`、调用栈、出错行 | 从最后一行识别异常种类，再向上定位调用路径。 | 不是所有用户输入错误都应在产品中打印 Traceback。 |
| 名称/对象绑定 | `examples/module_01/repl_and_names.py`；1.2 | 名称变化与对象关系 | 通过 REPL 验证名称绑定。 | 不是生产日志格式。 |
| 文件和路径失败 | 模块 3、项目 3 | 受控路径/冲突错误 | 区分操作系统错误、验证错误和回滚边界。 | 不应向外暴露任意绝对路径。 |
| 配置与插件失败 | 项目 4；4.4 | `PluginConfigurationError`、`UnknownPluginError` | 练习允许列表与字段闭集。 | 不应动态导入不可信模块。 |
| 结构化并发失败 | `examples/module_06/async_reliability.py`；6.4 | 超时、取消、清理与失败传播 | 理解 `TaskGroup` 收尾语义。 | 超时不表示远端副作用未发生。 |

## 2. 受控领域失败与公开契约

| 模块 / 项目 | 输入或状态 | 受控错误或公开结果 | 调用者可依赖的边界 | 内部细节禁止项 |
|---|---|---|---|---|
| 3 自动归档 | 目标存在同名文件 | 拒绝覆盖，保留源文件 | 不静默替换现有文件。 | 文件正文、任意系统路径。 |
| 4 插件系统 | 未知插件或未知配置字段 | `UnknownPluginError` / `PluginConfigurationError`；CLI 退出码 `2` | 允许列表和 Schema 在执行前验证。 | 动态导入路径、敏感审计正文。 |
| 6 API 服务 | 无效请求、资源不存在、存储失败 | `422 invalid_request`、`404 note_not_found` 或受控 `StorageError` | 稳定 HTTP 状态、错误代码与请求 ID。 | SQL、堆栈、数据库凭据、原请求正文。 |
| 7 API 采集器 | 非 HTTPS、robots 拒绝、存储损坏 | 受控 CLI JSON、退出码 `2`、领域错误 | 请求在网络调用前完成协议/规则校验。 | 抓取正文、认证头、完整上游错误。 |
| 8 工作流服务 | 幂等冲突、队列满、超时、关停 | `409`、`503`、`failed/timeout`、`pending/interrupted` | 不伪装成功；恢复候选明确标记。 | handler 正文、内部队列细节、秘密。 |
| 9 LLM 合同客户端 | 未知模型、拒答、空内容、非法 JSON | `LlmRequestError`、结构化输出受控失败 | 本地 Schema 与有限重试优先。 | prompt、用户正文、完整供应商响应、密钥。 |
| 10 RAG 合同工作台 | 非法语料/查询、空证据、非法引用 | `DocumentError`、`QueryError`、`not_enough_evidence`、`AnswerContractError` | 无证据时本地拒答，不调用传输。 | 查询、块正文、向量、提示、凭据。 |
| 11 受限 Agent 核心 | 未知动作、预算耗尽、审批拒绝、非法夹具 | 受控停止原因或 `EvaluationFixtureError` | 模型外状态/工具/预算/审批验证。 | 目标、参数、工具结果、注入正文。 |
| 12 框架采用合同 | 过期/跨租户/拒绝恢复、夹具损坏 | 受控合同错误 | 框架能力不绕过应用验证。 | checkpoint 正文、候选参数、凭据。 |
| 13 委派合同 | 越权角色、重复委派、身份错配 | 受控拒绝或稳定汇总状态 | 委派不扩散权限。 | 子任务正文、工具输出、用户数据。 |
| 14 评测门禁 | 硬阻断、未运行、软回归、夹具损坏 | `rejected` / `GateFixtureError` | 发布决定不被单一分数掩盖。 | trace 正文、案例输入、模型结果。 |
| 15 运行准备 | 过期/撤销/缺失秘密元数据、恢复未演练、Runbook 不全 | `rejected` / `ReadinessFixtureError` | 不读取秘密值，不启动部署。 | 秘密值、环境变量、端点、完整配置。 |

## 3. 处理顺序：从 Traceback 到修复

| 步骤 | 操作 | 说明 |
|---:|---|---|
| 1 | 复现 | 使用最小、受控、非敏感输入复现；不把生产正文粘到公开问题里。 |
| 2 | 读最后一行 | 确认异常类、消息类别和失败边界。 |
| 3 | 向上读栈 | 找到最靠近自己代码的调用点与输入验证点。 |
| 4 | 分类 | 区分编程缺陷、用户输入、依赖不可用、取消/超时、权限/策略与结果未知。 |
| 5 | 设计公开边界 | 已知可预期失败应映射到稳定错误代码/状态；未知 bug 留给受控诊断与告警。 |
| 6 | 写回归测试 | 用最小夹具固定失败合同、隐私边界和不应发生的副作用。 |
| 7 | 更新 Runbook/ADR | 如果失败影响恢复、权限、数据或发布决策，补充运行手册与架构记录。 |

## 4. 退出码与 HTTP 状态速查

| 通道 | 成功 | 预期调用者错误 | 系统/依赖错误 | 说明 |
|---|---:|---:|---:|---|
| 课程 CLI | `0` | 通常 `2` | 按项目合同定义 | stdout 放用户结果，stderr 放最小诊断。 |
| HTTP API | `2xx` | `4xx` | `5xx` 或受控不可用结果 | 使用稳定错误代码和请求 ID，不回显内部异常。 |
| 静态评测 | `passed=true/false` | 夹具错误显式拒绝 | 不将未运行当作通过 | 报告仅保留受控 ID、计数、状态和决定。 |

## 5. 出版审校提醒

Traceback、测试名称、日志和报告示例应使用教学夹具或脱敏占位符。任何讲义中出现的密钥、token、真实端点、用户正文、完整 SQL、完整供应商响应或真实生产路径都应视为出版阻断项。
