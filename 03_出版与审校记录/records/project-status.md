## 统一状态定义

| 状态 | 含义 |
|---|---|
| 未启动 | 只有蓝图或验收意图，尚未建立可运行骨架。 |
| 准备中 | 已有环境、边界或最小骨架，业务能力尚未实现。 |
| 实现中 | 功能、测试、文档和错误处理正在同步构建。 |
| 初步完成 | 核心验收已通过，但尚未纳入全书统一工程化和发布门禁。 |
| 已完成 | 已通过功能、可靠性、安全、文档、可复现与回归验收。 |

> **维护约定：** 此文件只保留每个项目的最新状态；历史演进信息应写入项目 README、变更记录或测试报告，而不是重复追加到状态表。
