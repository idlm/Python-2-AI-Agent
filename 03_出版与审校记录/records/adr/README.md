# 架构决策记录（ADR）总览

本目录记录课程在跨模块反复出现、且影响实现与出版措辞的关键架构取舍。ADR 说明课程当前的教学决定及其证据边界；它们不是对读者生产系统的通用合规、性能、安全或部署承诺。

| ADR | 主题 | 状态 | 关联模块 | 关键禁止误读 |
|---|---|---|---|---|
| [ADR-001](ADR-001-model-output-is-not-authority.md) | 模型输出不是权限来源 | 已采纳 | 9–15 | 模型、提示或框架不能自动授权工具/副作用。 |
| [ADR-002](ADR-002-offline-evaluation-first.md) | 离线评测优先，真实烟雾只验证接线 | 已采纳 | 9–15 | 单次真实调用不证明质量、安全、容量或生产就绪。 |
| [ADR-003](ADR-003-default-deny-and-side-effect-isolation.md) | 默认拒绝并隔离副作用 | 已采纳 | 3–15 | 允许列表、审批和预算不等同于真实副作用已安全接入。 |
| [ADR-004](ADR-004-recovery-and-operational-readiness-are-contracts.md) | 恢复与运行准备必须是独立合同 | 已采纳 | 8、11、12、14、15 | 备份/健康/CI 存在不证明可以恢复或生产运行。 |

## 状态定义

| 状态 | 含义 |
|---|---|
| 拟议 | 正在收集证据和替代方案，尚未作为课程统一边界。 |
| 已采纳 | 已在正文、项目、测试或出版材料中形成一致合同。 |
| 已取代 | 新决定替代旧决定；旧记录保留以解释历史。 |
| 已弃用 | 不再建议使用，但保留以解释不采用原因。 |
