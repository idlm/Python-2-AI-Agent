# 第 3.1 章：文件系统与路径——程序如何定位真实世界的数据

## 1. 本章目标
理解文件、目录、绝对路径、相对路径和当前工作目录，并能安全定位练习文件。

## 2. 为什么学习
自动化的对象通常是文件；路径错误可能导致读不到数据或操作错误位置。

## 3. Agent 中的作用
RAG 文档、日志、检查点和工具输出都需可靠路径与存储边界。

## 4. 前置知识
完成模块 0 的终端与工作目录章节。

## 5. 概念解释
文件保存内容，目录组织文件；绝对路径从根位置开始，相对路径从当前工作目录开始。

## 6. 生活化比喻
路径像地址；相对路径像“从你当前位置向左”，绝对路径像完整街道和门牌。

## 7. 原理分析
相同相对路径在不同 CWD 可能指向不同位置；自动化脚本必须显式确认根目录与目标路径。

## 8. 最小示例
```python
from pathlib import Path
project_root = Path.cwd()
print(project_root)
print((project_root / "examples").exists())
```

## 9. 逐行解释
`Path.cwd()` 读取 CWD；`/` 组合路径；`exists()` 检查目标是否存在而不修改文件。

## 10. 常见错误
不要把个人绝对路径写死；不要根据文件名猜测目标路径；不要在未确认位置执行批量移动。

## 11. Traceback 分析
`FileNotFoundError` 表明程序请求的路径不存在；先打印 CWD 和完整路径。

## 12. 错误案例
归档脚本在错误目录运行，把练习文件当成待移动文件。

## 13. 改进方案
使用项目根目录、相对路径、Dry Run 和操作前路径检查。

## 14. 工程实践
路径使用 `pathlib`；每次文件操作记录来源、目标和结果。

## 15. 性能优化
目录很大时避免重复扫描；先过滤扩展名和范围。

## 16. 安全问题
限制允许操作的根目录；拒绝 `..` 路径穿越和符号链接陷阱；删除前须审批。

## 17. 小项目
列出指定练习目录中的文件名，但不修改它们。

## 18. 单元测试
测试路径拼接、存在判断和拒绝根目录外目标。
