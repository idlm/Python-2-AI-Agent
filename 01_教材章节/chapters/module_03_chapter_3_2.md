# 第 3.2 章：pathlib 与安全文件操作

## 1. 本章目标
用 `Path` 安全组合、检查与读取项目内文件。

## 2. 为什么学习
字符串路径易出现平台、分隔符和目录错误。

## 3. Agent 中的作用
文档导入、日志写入与检查点保存都依赖受控文件操作。

## 4. 前置知识
完成第 3.1 章。

## 5. 概念解释
`pathlib.Path` 用对象表达路径；`read_text`、`write_text`、`iterdir` 读写和遍历文件。

## 6. 生活化比喻
Path 像地址对象，不只是手写地址字符串；它能帮助组合与检查位置。

## 7. 原理分析
先解析路径、确认根目录和存在性，再读取；写入前创建必要目录并避免覆盖未知文件。

## 8. 最小示例
```python
from pathlib import Path
path = Path("notes.txt")
if path.exists():
    print(path.read_text(encoding="utf-8"))
```

## 9. 逐行解释
创建相对路径对象；检查存在；使用指定编码读取文本。

## 10. 常见错误
忽略编码；对不存在路径直接读取；将目录当文件操作。

## 11. Traceback 分析
`FileNotFoundError` 表示路径不存在；`IsADirectoryError` 表示文件操作目标实际是目录。

## 12. 错误案例
自动归档在未检查后缀和根目录时移动所有文件，包括配置或密钥。

## 13. 改进方案
设置允许根目录、白名单后缀、Dry Run、操作日志与可回滚记录。

## 14. 工程实践
所有文件读写显式指定编码；函数接收 `Path` 或受验证路径；测试使用临时目录。

## 15. 性能优化
大文件流式处理；大量目录遍历过滤并避免重复 `stat`。

## 16. 安全问题
拒绝根目录外路径和符号链接绕过；默认只读，写入和移动需要确认。

## 17. 小项目
列出归档目录中的 `.txt` 文件及大小，只展示不移动。

## 18. 单元测试
使用临时目录创建样本，测试读取、后缀过滤和拒绝不存在文件。
